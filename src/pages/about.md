This is a static site built with [Astro](https://astro.build). Posts are plain
markdown files that live in `src/content/posts/`; a push to `main` rebuilds and
redeploys the whole thing to GitHub Pages.

## Why markdown

Every post is a file. That means the archive is greppable, diffable, portable,
and outlives whatever renders it. No database, no CMS, no lock-in.

## Colophon

- **Framework** — Astro, static output, zero client JavaScript except the theme toggle.
- **Type** — Charter for body copy, the system UI stack for everything else.
- **Highlighting** — Shiki, with matched light and dark themes.
- **Hosting** — GitHub Pages, deployed by GitHub Actions.

Replace this page by editing `src/pages/about.md`.
